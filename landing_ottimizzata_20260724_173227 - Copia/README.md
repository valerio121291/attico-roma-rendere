# Attico Roma - Landing Page

## Installazione

1. Installa le dipendenze:
```bash
pip install -r requirements.txt
```

2. Avvia l'applicazione:
```bash
python app.py
```

3. Apri il browser su: `http://localhost:5000`

## Caratteristiche

- Design responsive
- Multi-lingua (IT, EN, ES, RU, ZH)
- Galleria con lightbox
- Prenotazione con calendario
- Sistema di recensioni
- Offerta sconto 10%
- Mappa interattiva
- Form di contatto
- WhatsApp Floating Button con animazione

## Personalizzazione

Modifica `dati.json` per cambiare prezzo, descrizioni, immagini e servizi.
